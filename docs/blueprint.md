# **App Name**: SimpleStart

## Core Features:

- Display Message: Display the static 'Hello, World!' message on the screen.
- Customizable Message: Allow the user to change the message from 'Hello, World!' to a custom text string.
- Message Saving: Save the current text in local storage so that it persists across browser sessions.
- Text Styling: Allow the user to change the color and size of the displayed message.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for a calm and professional feel.
- Background color: Light blue (#E8EAF6), visibly in the same hue family as the primary, but heavily desaturated for subtlety.
- Accent color: Violet (#7E57C2) as an analogous color for buttons and interactive elements, clearly contrasting in brightness and saturation.
- Font: 'Inter' (sans-serif) for a modern and neutral look.
- Simple and clean layout with the message prominently displayed in the center.
- Subtle fade-in animation on page load and message update.
